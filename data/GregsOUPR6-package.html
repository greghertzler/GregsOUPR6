GregsOUPR6-packageR Documentation

GregsOUPR6: Real Options for Adoption and Resilience: Ornstein-Uhlenbeck Process: R6 Objects

Description

A complete set of functions for maximum likelihood estimation and for the calculation of probabilities, option prices, decision thresholds, visiting times, first passage times and more–everything for a real options analysis.
