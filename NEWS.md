# GregsOUPR6 1.4.5.0

## Major changes

* Add R6 object and RShiny tab for Monte Carlo simulation of the Ornstein-Uhlenbeck Process.
* Add tutorials for Monte Carlo simulation and update other tutorials to include simulation.
* Move all calculations from R6 objects to Rcpp and RcppParallel and calculate thousands of times faster.

## Minor changes

* Stabilise timings in the RShiny app.
* Reorganise RShiny Maximum Likelihood tab to improve workflow.
* Add clipboard copy to RShiny app.
* Update and consolidate R6 plots.
* Add clipboard write to R6 objects.
* Add functions to launch RShiny, tutorials and help and to read curated data from the console.
* Conditionally compile optional packages RcppParallel and sitmo.
