# GregsOUPR6

Real Options for Adoption and Resilience: Ornstein-Uhlenbeck Process

Description:  
Analytical, Finite Difference, Maximum Likelihood and Monte Carlo
methods–a complete set of functions for maximum likelihood estimation
and the calculation of probabilities, option prices, decision
thresholds, visiting times, first passage times and more–everything for
a real options analysis.

Version:  
1.4.5.0 (Stochastic Process.Modules.Help.Bugs)
