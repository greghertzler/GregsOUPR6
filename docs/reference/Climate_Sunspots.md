# Sunspot Numbers

International Sunspot Number V2.0.

## Format

csv file with 3316 rows and 2 columns

## Source

https://doi.org/10.24414/qnza-ac80

## Details

- DecimalYear: time variable in daily increments

- Average: Simple average of the daily total sunspot number over all
  days of each calendar month.

Sunspot numbers and groups of sunspot numbers, averaged by month.

Royal Observatory of Belgium
