# Soil Health with Stubble Management

CSIRO Harden Long-Term Tillage Experiment. v3. CSIRO. Data Collection.

## Format

csv file with 30 rows and 5 columns

## Source

https://doi.org/10.25919/2jqe-mz45

## Details

- Year: time variable in sporadic increments

- N Burn: kilograms per hectare of mineral soil nitrogen in the soil
  profile from 0 to 160 millimetres with stubble burning

- N Bash: kilograms per hectare of mineral soil nitrogen in the soil
  profile from 0 to 160 millimetres with stubble bashing

- W Burn: millimetres of water in the soil profile from 0 to 160
  millimetres with stubble burning

- W Bash: millimetres of water in the soil profile from 0 to 160
  millimetres with stubble bashing

Soil nitrogen and water in the top 160 millimetres.
