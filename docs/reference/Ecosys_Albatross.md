# Albatross Egg Counts

The Australian Threatened Species Index, 2024.

## Format

csv file with 60 rows and 4 columns

## Source

https://tsx.org.au/tsx2024

## Details

- Year: time variable in annual increments

- Wandering Albatross: egg count

- Black-browed Albatross: egg count

- Grey-headed Albatross: egg count

Nesting egg counts of three Albatross species in Tasmania.

Australian Government, Department of Climate Change, Energy, the
