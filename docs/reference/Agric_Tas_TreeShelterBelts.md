# Tree shelter belts in Tasmania

CSIRO Perennial Prosperity Project.

## Format

csv file with 52 rows and 3 columns

## Source

corresponding author, Tim Capon <tim.capon@csiro.au>

## Details

- Year: time variable in annual increments

- With trees: sheep gross margins per paddock with tree shelter belt

- Without trees: sheep gross margins per paddock without tree shelter
  belt

Simulated effects of shelter belts with prices and costs for sheep
production.
